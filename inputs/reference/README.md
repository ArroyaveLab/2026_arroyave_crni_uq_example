# Independent Cr--Ni topology reference

`CrNi-16Tan.tdb` is the Tang--Hallstedt Cr--Ni assessment distributed in
Bengt Hallstedt's SGTE binary collection under CC BY 4.0. It is included
unchanged; its SHA-256 is pinned in `../UPSTREAM.json`.

- F. Tang and B. Hallstedt, *Calphad* 55 (2016) 260--269,
  https://doi.org/10.1016/j.calphad.2016.10.003
- B. Hallstedt, *Calphad* 89 (2025) 102833,
  https://doi.org/10.1016/j.calphad.2025.102833
- Collection record and supplementary files:
  https://doi.org/10.1016/j.calphad.2025.102833
- License: https://creativecommons.org/licenses/by/4.0/

The file is used only to validate the phase-diagram graph over 1000--1600 K.
Its thermodynamic parameters do not enter the ESPEI calibration.
